PhotoHub プライバシーポリシー

最終更新日：2026年11月22日

1. PhotoHub について

PhotoHub は、利用者（家族）が自宅に置く NAS と、利用者のスマホの間で写真を管理する、個人・家族向けのアプリです。開発者がサーバーを運営したり、利用者のデータを集めたりすることはありません。

2. 扱う情報と、その保存先

  • 写真・動画とその情報（撮影日時、撮影場所、ファイル名など）：利用者のスマホと、利用者自身の NAS に保存されます。
  • NAS へのログイン：利用者の Synology アカウントのユーザー名とパスワードは、利用者自身の NAS で確認するためだけに使い、保存しません。スマホには、その端末専用の鍵だけを保存します。
  • Google ドライブ（利用者が有効にした場合のみ）：Google の権限「drive.file」を使います。PhotoHub が扱えるのは、PhotoHub がその利用者のドライブにアップロードしたファイルだけで、ドライブのほかのファイルは読みません。アップロードした写真は利用者本人のドライブ（フォルダ「PhotoHub」）に保存され、利用者が設定した範囲を過ぎ、NAS に保存されたことを確認したものは削除します。

3. 第三者への提供

開発者や第三者に、写真や個人情報を送ることはありません。広告、アクセス解析、トラッキングの仕組みは入っていません。アプリの更新の有無を確認するために、GitHub の公開ページ（このリポジトリのリリース）にアクセスします。

4. Google ユーザーデータの利用について

PhotoHub による Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。Google ドライブのデータは、利用者の写真のバックアップと表示のためだけに使います。

5. 削除

アプリの設定で Google ドライブの利用をオフにするか、Google アカウントの「サードパーティによるアクセス」から PhotoHub の許可を取り消すと、PhotoHub はドライブにアクセスしなくなります。ドライブ上のフォルダ「PhotoHub」は、利用者がいつでも削除できます。NAS 上のデータは、NAS の管理者が管理します。

6. お問い合わせ

GitHub の Issues からご連絡ください。

Summary (English)

PhotoHub stores photos only on the user's phone, the user's own NAS and, if enabled, the user's own Google Drive (scope drive.file: only files PhotoHub created). No data is sent to the developer or third parties; there are no ads or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
