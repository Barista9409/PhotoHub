# PhotoHub 家族向けガイド

PhotoHub は、家族の写真を家の Synology（写真の保管庫）にしまって、いつでも見られるようにするアプリです。
**スマホで撮った写真は、アプリが自動で Synology にしまいます。** むずかしい設定はいりません。

> Synology の準備は、管理者（家族の中で設定を担当する人）がすませてあります。わからないことは管理者に聞いてください。

---

## 1. アプリを入れる（5分）

1. スマホのブラウザでこのリンクを開きます
    **https://github.com/Barista9409/PhotoHub/releases/latest/download/PhotoHub.apk**
    （管理者から LINE などでリンクが届いていれば、それを押します）
2. ダウンロードしたファイルを開きます
3. 「この提供元のアプリを許可」と出たら、**許可**します

## 2. ログインする

1. **家の Wi-Fi につないだまま**、PhotoHub を開きます（家の Synology が自動で見つかります）
2. 管理者から教えてもらった **ユーザー名とパスワード** を入れます
    - Synology Photos を使っている人は、それと同じです
    - 「Synology Photos のアルバムも同期する」には**チェックを入れたまま**にします
3. 「写真へのアクセス」と「通知」を聞かれたら、**許可**します

## 3. はじめに1回だけ

右下の「**設定**」を開いて、次の2つをします。

1. 「同期設定」の「**電池の最適化から外す（おすすめ）**」を押して、「許可」を選びます
    （これをしないと、写真がなかなか送られないことがあります）
2. **Google フォトのアプリのバックアップをオフ**にします
    （Google フォトのアプリ →右上の自分のアイコン →「バックアップ」をオフ）

これで準備はおしまいです。

## ふだんの使い方

| したいこと | やりかた |
|---|---|
| 写真をしまう | **なにもしなくて大丈夫。** 撮ると数分で Synology に送られます（Wi-Fi のとき） |
| 写真を見る | 下の「**マイフォト**」→ いちばん上の「**すべての写真**」。「年・月・日」で並べ方を変えられます |
| いちばん上に戻る | 「すべての写真」で、下の「マイフォト」をもう一度押す |
| 新しい写真を取り込む | 「すべての写真」を**下に引っぱる** |
| 探す | 右上の **虫めがね**。「犬」「海」「2023年8月」「沖縄」などで探せます |
| 家族の写真を見る | 下の「**ファミリー**」。いちばん上で「アルバム・フォルダ・すべての写真」を切り替えます |
| アルバム | 下の「**マイフォト**」→ いちばん上の「**アルバム**」（開いたときはここ）。人ごと・旅行・毎月のふりかえりなどを、アプリが自動で作ります |
| お気に入り | 写真を開いて **♡** |
| 写真を消す | 写真を長押しして選び、上の**赤いゴミ箱**。30日間はゴミ箱から戻せます |
| 写真を回す | 写真を開いて、上の回転ボタン |
| 外で見る | 下の「Tailscale を入れる」を読んでください |

**スマホの容量が足りないとき**：設定 →「データ管理」→「整理とゴミ箱」→「スマホの空き容量」。Synology にしまった古い写真をスマホから消します（PhotoHub ではそのまま見られます）。

---

## 外出先で見る（Tailscale を入れる）

家の外から見るには、「Tailscale」というアプリがいります。

1. Google Play で「**Tailscale**」を入れます
2. 管理者から届いた招待を開いて、参加します（または、管理者に教えてもらったアカウントでログイン）
3. Tailscale をオンにしたまま PhotoHub を開くと、外でも写真が見られます

---

## Google フォトから引っ越す（一度だけ）

Google フォトにある昔の写真を、Synology に移します。**かならずこの順番で**してください。

1. **アプリを最新にする**（設定 →「アプリ」→「アプリの更新」）
2. **スマホの写真を先に送り終える**
    設定 →「データ管理」→「ライブラリの内訳」で、「このスマホにしかない」が **0枚** になるまで待ちます
3. **Google から写真をまとめて出す**
    1. ブラウザで **https://takeout.google.com** を開きます
    2. 「選択をすべて解除」→「**Google フォト**」だけにチェック →「次のステップ」
    3. 配信方法を「**ドライブに追加**」にして、「エクスポートを作成」
    4. あとは待つだけです。Synology が自動で受け取って取り込みます（数時間〜1日）
    - 進み具合：設定 →「データ管理」→「Google フォトからの移行」→「取り込みの状況」
    - Synology への受け取りの設定がまだなら、管理者に「Takeout の受け取りをお願い」と伝えてください
4. **最後に Google フォトを空にする**
    設定 →「データ管理」→「Google フォトからの移行」→「Google フォトを空にする」
    - 画面の上が「**確認OK**」になっているときだけ、Google フォトのアプリで消してください
    - **注意：Google フォトで消すと、スマホの中の写真も一緒に消えます。** Synology にしまってあるので、PhotoHub では見られます

## 困ったとき

| こんなとき | すること |
|---|---|
| 「Synology が見つかりません」 | 家の Wi-Fi につながっているか確かめて、「もう一度探す」 |
| ログインできない | ユーザー名とパスワードを管理者に確かめる |
| 写真が送られない | 設定 →「同期設定」→「今すぐ同期・保存」を押す。「電池の最適化」を外したか確かめる |
| 外で見られない | Tailscale がオンになっているか確かめる |
| Tailscale をオンにすると、ほかのアプリがネットにつながらない | Tailscale のアプリで「**Exit Node（出口ノード）**」が「なし（None）」になっているか確かめる。それでも直らなければ、Tailscale の設定の「**Split tunneling（アプリ別）**」で PhotoHub だけを通すようにする。くわしくは管理者に |
| アプリが止まった | 設定 →「アプリ」→「エラーの記録」→「まとめてコピー」して、管理者に送る |

もっと詳しいこと（Synology の設定など）は、管理者向けの「導入ガイド」に書いてあります。
